Installation

  1. Open MATLAB R2024a and navigate to the file location.
  2. Double-click 'SystemComposerSysMLConnector_R2024a_Draft.mltbx' in the MATLAB Current Folder window.
  3. Click 'Install' and then accept the license agreement.
